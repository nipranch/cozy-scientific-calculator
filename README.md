
# ☕ CozyCalc — Scientific Calculator

A compact, responsive scientific calculator designed with a minimal and cozy user interface.

Built using HTML, CSS and JavaScript with a focus on simplicity, responsiveness and usability across devices.

## ✨ Features

- Basic arithmetic operations
- Percentage calculations
- Trigonometric functions
- Inverse trigonometric functions
- DEG / RAD modes
- Logarithms
- Natural logarithm
- Square root
- Powers
- Factorials
- Mathematical constants
- Parentheses
- Calculation history
- Keyboard support
- Responsive design
- Scientific calculator help guide
